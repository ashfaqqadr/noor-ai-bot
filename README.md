# Noor AI Crypto Demo Bot

## What it does
- Public Binance market data for BTC/USDT, ETH/USDT, BNB/USDT and SOL/USDT
- Candlestick chart with EMA 9, EMA 21, and RSI 14
- BUY / SELL / NO TRADE educational signals
- Paper trading with a virtual 10,000 USDT account
- Optional auto demo mode: checks for a new closed candle about every 30 seconds and processes each candle once
- Virtual stop-loss / take-profit checks
- Never submits real orders and does not need exchange API keys

## Easiest Android setup
1. Sign in to GitHub in your mobile browser and create a repository named `noor-ai-crypto-demo`.
2. Upload `app.py`, `requirements.txt`, and this `README.md`.
3. Open Streamlit Community Cloud and sign in with GitHub.
4. Create a new app, choose the repository and branch, set main file path to `app.py`, then deploy.
5. Open the app link on your Android phone.

Free hosting terms and availability can change. Do not upload API keys or passwords.

## Important
This is a learning prototype, not a proven AI predictor. All orders are simulated. No guaranteed win rate or profit. Signals are generated by simple EMA/RSI rules and should be backtested before drawing conclusions. Paper account state is held in the running app session and may reset if the app restarts.
